# StoreGamer

Frontend React + Vite para vender consolas usando los recursos del MockAPI proporcionado.

## Ejecutar

```bash
npm install
npm run dev
```

## Recursos utilizados

- `GET /producto`: catálogo, precio, stock, imagen y estado.
- `GET /categoria`: filtros del catálogo.
- `POST /producto`: alta desde Inventario.
- `DELETE /producto/:id`: baja desde Inventario.
